# The Hi-Fi Archives

A small corner of the internet for sharing what I’m into, what I’m curious about, and what I might explore next.

This page is a work in progress, and I can change it whenever I like. It’s an introduction—not a résumé or a record of personal details.

## About the page

The site is a simple landing page made with HTML and CSS. It currently has:

- A short introduction
- A few things I’m interested in
- A note about what I might explore next
- A responsive layout for phones and larger screens

## Make it yours

Edit `index.html` to change the words, colors, and sections. You can keep your introduction anonymous and share only what you’re comfortable sharing.
